# 天結いキャッスルマイスター 简体中文汉化测试版

## 包里有什么

- `BIN\` 文件夹：已汉化的游戏脚本文件（全选复制即可）
- `AGF\` 文件夹：已汉化的 UI 图片文件（全选复制即可）
- `AGERC.DLL`：主菜单栏汉化补丁（复制到游戏根目录覆盖同名文件）
- `Amayui-CN_cnjp.ttf`：中文字体
- 本说明

## 安装步骤

1. **复制一份游戏**：把整个游戏目录复制一份（放到别的文件夹即可），之后的操作都在副本上进行，原版保持不动。
2. 在副本根目录把 `AGE-EXTEND.TTF` 改名（如 `AGE-EXTEND.TTF.bak`）或移出（**必须**，否则中文不生效）。
3. **复制脚本补丁**：把 `BIN\` 文件夹里的全部 .BIN 全选复制到副本的游戏根目录（有同名就覆盖）。
4. **复制 UI 图片补丁**：把 `AGF\` 文件夹里的全部 .AGF 文件复制到副本的游戏根目录
   （游戏会优先读取根目录的 AGF 覆盖原图；有同名就覆盖）。
5. **复制主菜单补丁**：把 `AGERC.DLL` 复制到副本的游戏根目录，覆盖同名文件（主菜单栏汉化补丁）。
6. **安装字体**：双击 `Amayui-CN_cnjp.ttf` → 安装（如果游戏正在运行，先完全退出）。
7. **启动游戏**：用 Locale Emulator 以「日语（日本）」区域运行——右键 `AGE.EXE`→
   Locale Emulator → 日语运行。**不要**直接用中文区域启动（会乱码）。
   **游戏目录路径需要是英文或日文，不能包含中文**（否则启动或显示可能异常）。
8. **设置字体**：进游戏设置界面，把字体分类都设为 **Amayui CN**（説明文、パラメータ文字/数字、
   ＡＤＶルビ、ＡＤＶメッセージ 等）。其中 **『パラメータ文字/数字』就是设置界面自身的字体**，
   务必也改成 Amayui CN，否则设置界面文字仍是日文/方块。

## 存档位置

- 本补丁的存档在：`%USERPROFILE%\AppData\Local\Eushully\天結いキャッスルマイスター`
- 市面上的汉化版（心愿屋版）存档路径与此不同，但**存档本身通用**，只是位置不同。
- 部分信息（例如称号）保存的是获取时的内容，使用旧存档会导致部分内容展示异常。

## 常见问题

- **中文没生效？** 确认 `AGE-EXTEND.TTF` 已移出、字体已安装、用日语区域启动，然后重启游戏。
- **游戏内按钮/UI 图片还是日文？** 确认 `AGF\` 里的 .AGF 已复制到游戏根目录。
- **窗口顶部主菜单栏还是日文？** 确认 `AGERC.DLL` 已复制并覆盖到游戏根目录。
- 字体设置一次即可，之后自动记住（保存在 `SAVE.DAT`）。
- **想还原原版？** 直接玩没动过的原版目录即可；或删掉打过补丁的副本，重新复制一份再装补丁。

## 反馈

- 遇到问题请发**截图**（正文、设置界面、报错窗口均可）和简单描述；
- 如果游戏崩溃，请把 `%LOCALAPPDATA%\CrashDumps\` 里最新的 `AGE.EXE.*.dmp` 一起发来；
- 觉得译名或翻译不对的地方欢迎指出（说明大概在哪看到的即可）。
