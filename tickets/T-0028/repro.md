# T-0028 · 过程文档（repro.md）

## 2026-09-14

## 复现（产品路径，任意平台）

1. 启动 emulator，进入任意 ADV 场景（序章或常规场景）。
2. **不要碰鼠标**：右侧侧边栏一出现就是「展开」外观（16 个条目可见）。
3. 把光标在屏幕内移动一次（离开右侧条带区域）⇒ 侧边栏收起到屏幕右侧。
4. 此后 hover 条带 → 展开、移开 → 收起，一切正常。

## 变量控制（用来区分候选 A / B）

- **A（进入时合成 hover-enter）**：进场景**之前**把光标停在右侧条带区域内（展开态条带 = x∈[0x49c,0x500]=[1180,1280]、y∈[0,0x281]=[0,641]；收起态展开标签 = (0x4ce,0xe9) 50×260）⇒ 若只有这种情形才复现，A 成立。
- **B（`139a` 粘住）**：先点一次侧边栏底部那个按钮（`i090 4a5 23d 3e 1d`，即 (1189,573) 62×29）使 `global 139a` 变 -1，再进任意场景 ⇒ 若无论光标在哪都复现，B 成立。
