  ② 过渡项（段 1 的 `101102`、段 4 的 `101022`）的 α：255→199→145→86→32（2500ms）/ 229→185→137→94→46→0（3000ms）——**依次衰减**；
  ③ 卡片→人物轮廓的换图（同一 handle `101020`，槽 7 的图从 `0x7a` 换成 `0x7d`）发生在黑幕 **α=255** 时 ⇒ 不可见。
- ⇒ 「跳变」不在模型层，只可能在**像素层**。

### 2. 根因（代码 + 数学，两处共用）

`#compositeTransitions` 类别 3 的累加是 canvas 默认的 **source-over**，而权重表是**归一化加权平均**
（`total = 32×1 + 中心 3 = 35`，即 Σw/35 = 1）：source-over 的累积 α = `1 - (34/35)^33 ≈ 0.6158`
⇒ **合成幕只有 62% 不透明**，底下那张满屏黑（`mesh 0x0` / 黑幕）透出 **38%** = 用户看到的那层"黑色遮罩"。

### 3. 确定性测量（真 canvas；源 = 不透明中灰 128）

| 变体 | 读回的 RGBA | α |
|---|---|---|
| source-over（修前） | [126,126,126,160] | **0.627** |
| `lighter` + 浮点 α（第一版） | [142,142,142,246] | 0.965（8bit 量化残留 3.5%） |
| **`lighter` + 整数 α 且 Σ=255（落地）** | [137,137,137,255] | **1.000** |

残差：8bit 前乘色逐层四舍五入 ⇒ 中灰累到 ≈137（+7% 亮度）；精确解需浮点累加（WebGL/Pixi pass）。

### 4. 修法与验证

- `scene/transition.ts` 新增纯函数 `transitionBlurAlphas(samples, centerWeight, centerIdx)`（整数 α，Σ = 255）；
- `pixiBackend` 类别 3：`globalCompositeOperation = 'lighter'` 累加，用完还原 `'source-over'`。
- 运行期 before/after（同一驱动同一 delay，窗口内位置可比）：
  shot#1 **77.8 → 126.6（1.63×）**、shot#2 **22.7 → 34.1（1.50×）**；
  ★理论 `1/0.6158 = 1.62×` ⇒ 修前那 38% 的黑纱正是两个跳变的来源。
- 守卫：`test/transition-render-wiring.test.ts` 新增**单元**（`transitionBlurAlphas`：Σα=255、中心加权、
  误差 ≤1/255、退化 1/2/0 采样）+ **源码棘轮**（必须 `lighter` 且还原 `source-over`）。
