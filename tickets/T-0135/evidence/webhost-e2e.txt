# Phase 2 端到端实跑记录（2026-09-23，本机 macOS）

## 形态
Node web 宿主（独立进程，只绑 127.0.0.1）→ Electron 当**哑浏览器**（show:false，无 preload/IPC）
加载 http://127.0.0.1:8901/ → `bridge.js` 把 `window.api` 装成 HTTP+SSE 实现 → 模拟器 boot 到 TITLE。

命令：
  npm run build:electron
  npx electron tools/webhost-shot.cjs --port 8901 --instance shot --wait-ms 45000

## 顺带抓到的真 bug（假 fetch 测不出来的那种）
`webBridge` 原先把 `fetch` 存进字段再以**桥实例**为 receiver 调用 ⇒ 浏览器报
`TypeError: Failed to execute 'fetch' on 'Window': Illegal invocation`（Node 的 fetch 不挑 receiver
⇒ 注入假 fetch 的单测抓不到）。已改为裸调包装，并补了一条"receiver 不许是桥实例"的断言
（`test/web-bridge.test.ts`，13/13）。
