## 3. 第二渲染者防护

另开一条**真的** SSE 长连（就是第二个页面会做的事：`GET <实例>/events`，`Accept: text/event-stream`），
在它活着的前后各读一次 `/health`：

```text
--- before（只有无头自持页）---
{…,"viewers":1,"viewersWarn":false}

--- after（多了第二个渲染者）---
{…,"viewers":2,"viewersWarn":true}
[web] 观察者 #1 接入（现共 2 个）
[web] ⚠ 第二渲染者：实例 hl-a 现在有 2 个**外部**渲染页（另有无头自持页 1 个） ⇒ 多个 VM 会抢同一份 overlay/log。请只保留一个页面（关掉多余的标签/面板实例）。

--- 第二个渲染者断开后 ---
{…,"viewers":1,"viewersWarn":false}
[web] 观察者 #1 断开（现共 1 个）
```

## 4. 复现命令（三条，按顺序）

```bash
# ① 起一个"agent 可直接驱动"的实例（不需要人开面板）
cd app/amayui-emulator && node --import tsx src/web/host.ts --instance hl-a --port 0 --attach-headless

# ② agent 驱动它（另开一个终端；坐标是引擎虚拟 1280×720）
curl -s -X POST http://127.0.0.1:3080/dsh-emulator/hl-a/api/debug-query \
     -H 'content-type: application/json' -d '{"args":["move 640 360"]}'
curl -s -X POST http://127.0.0.1:3080/dsh-emulator/hl-a/api/debug-query \
     -H 'content-type: application/json' -d '{"args":["capture"]}' > /tmp/cap.json

# ③ 观察者数与告警
curl -s http://127.0.0.1:<宿主端口>/health        # → {"viewers":N,"viewersWarn":N>1}
```
