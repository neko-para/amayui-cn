## 1. 方法（可复现）

1. **建索引**：从引擎构造函数区按 `opcode = (字节偏移 − 675996) / 4` 重建 dispatch 表（544 个已映射 opcode），
   与 `opcode-table.md` 的 574 行、`app/amayui-emulator/src/**` 里的注册点（`OPS` / `NATIVE_OPS` / `ENGINE_INTERNAL_OPS`）三方对齐。
2. **逐条核实**：每条 opcode / 能力 / 文档断言都要打开 handler 体的 raw 行号（不是相信文档转述），
   并检查 emulator 对应实现是否真的做了体里做的事。
3. **对抗性复核**：每条 finding 交由另一个 agent「尝试推翻」（自己重新打开行号、重新 grep 语料与字段读写点）。
   被推翻的剔除、需要改判的按复核值入账。复核分布见各报告的「方法与覆盖」节。
