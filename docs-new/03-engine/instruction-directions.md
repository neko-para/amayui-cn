# 03-engine · 指令功能方向分类（功能簇索引）

> 本文件只保留**功能方向粗分类**（声音/渲染/消息UI/输入/字符串/数据/脚本控制…），用于快速定位指令簇。
> **每条指令的语义 / 分析状态不再重复**——一律以真源 [`./opcode-table.md`](./opcode-table.md) 与数据层 `analysis/functions.json` 为准（handler=该 opcode 在本引擎 dispatch 表中的实现函数；读 `engine/天结_unpacked.exe_utf8.c` 对应对应 handler 体定归类）。
> 说明：`iXXXX` = opcode `0xXXXX`（未命名）；`load-int`/`save-int`/`save-string` 等 = 已命名 opcode。

## 8. 统计
- 消息窗/UI/文本/字体：33（最大簇，因这些脚本多属菜单/系统配置）
- 渲染/图像/图形：10
- 输入：9
- 数据/字段：5（含数组/内存操作）；字符串/查表：5；声音：2；版本/存档：1；脚本控制：1
- 无纯「文件」指令；`i25b`(图像加载)/`i2da`(CG 登记) 触资源文件，归入渲染/数据资源。

> **2025 补充归类的 10 条**（原未在本表）：`i0c0`/`i07f`/`i080`/`i142`/`i196`/`i300`/`i301`（消息窗/UI/文本/字体）、`i2ce`(显示模式)/`i217`(对象变换)（渲染）、`i12f`（数组/内存操作，多操作数地址）。
> 归类依据（各自 handler 体的字段/子系统）：`0xC0`=消息/系统配置字段 getter（`_this[174713]`，与 `0xC3` 成对，CONFIG.txt 读系统值）；`0x7F`=消息窗字段 getter（`_this[21668]`）；`0x80`=消息窗部件索引 setter（`_this[21631]`，`0x81/0x82` 同族）；`0x142`=消息/输入字段 setter（`_this[174812]`，属 `_this+699208` 输入态邻域）；`0x196`=文本注音（display-furigana，写消息窗文本区）；`0x300`/`0x301`=消息窗对象旗标/条目（`_this[122466+v]`/`_this[122486+v]` + `_this+21324` 容器）；`0x2CE`=显示模式 getter（`_this[167990]` ← 配置 `display:ScreenMode`，被 0x217 邻域的显示模式切换读作门）；`0x217`=对象变换（`sub_4ACF20`，op2/op3/op4 为 3 个 float）；`0x12F`=`sub_42AEA0` 取 op1/op2/op3 三个**数组地址**、`[op1]=0` 后按 op4 次数循环（数组/内存操作，非渲染）。
