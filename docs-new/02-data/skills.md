# 02-data · 技能表结构与数值字段

## 1. 三段并列定长数组

- ✅ **`skillId = 名串地址 − 0x1d4f4`**，段间 stride `0x3e8`(=1000)：
  - 名：`0x1d4f4 + id`
  - 简述：`0x1d8dc + id`（`0x1d8dc = 0x1d4f4 + 0x3e8`）
  - 题头/详述：`0x1dcc4 + 2*id` 与 `+1`（**2 槽/技能**；`0x1dcc4 = 0x1d4f4 + 2*0x3e8`）

## 2. 统计

- ✅ **450 技能**、id 稀疏于 1..803，六文件零冲突；`set-string` 汉化覆盖 100%。
- ✅ 唯一 #40「進行不可」只有名字、无描述。

## 3. 数值字段（语义未定）

- ✅ 基址 `0x6c65a2`：字段主序 `+ k*1000 + skillId`；另有 5 槽 `0x6c84e2`、13 槽 `0x6d2cda` 二维子数组。
- 🟡 已解释 89.6%，**语义未定**（标未解）。技能名/简述/题头为三段字符串数组，数值字段为引擎侧布局、语义在脚本层。

## 4. 交叉引用

- 技能名作为数据源用于 `app/amayui-toolkit` 的 metadata（`skills[]`），见 `./extraction.md`。
