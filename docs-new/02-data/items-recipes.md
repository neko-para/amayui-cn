# 02-data · 物品 / 建筑 / 配方

## 1. ITINIT（物品）

- ✅ 物品 id = `名称串地址 − 0x18e40`；字段为**并行数组**（同 id 索引）。
- ✅ 名称/效果用 `set-string`；装备效果命名统一（如「白刃流Ⅰ」，源自技能表口径，非「白刃格挡」）。
- ✅ 追加包 `$1$–$5$ITINIT` 为 AP01-05 追加装备/物品/敌人攻击名。

## 2. PLINIT（建筑/设施）

- ✅ 建筑基址 `0x1f5ba`；设施名/说明用 `set-string`（含城砦改造等）。
- ✅ 追加包 `$1$–$5$PLINIT` 为追加设施。

## 3. ALINIT（配方表）

- ✅ 配方表：标记 1 物品 / 2 建筑 + 材料（`プラン`，含城砦扩建图纸/机械防门等）。
- ✅ 配方/材料结构见数据表；物品建筑配方数据结构完整（字段语义）。

## 4. 交叉引用

- 配方/物品作为数据源用于 `app/amayui-toolkit` 的 `metadata.json`（items/buildings/recipes），见 `./extraction.md`。
