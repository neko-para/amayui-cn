## 坑（踩过一次，别再踩）

- `0x218`（pivot getter）/ `0x21A`（描画位置 getter）在 emulator **未注册** ⇒ 命中即硬报错；剧情路径大量使用这个惯用法（全库 i217 有 3353 处）
- ★存档槽族的状态码语义**不一致**：`0x1A0`/`0x19E`/`0x19F` 写 `op1`，`0x1A1` **不写**（引擎 `sub_42DDE0` 函数体无 `sub_42B4B0`，且调度器 raw 21217 丢弃 C 返回值）⇒ 读 `i1a1` 的 `op1` 只会拿到陈旧值/池值（本脚本给的 `f7ffd` 就是占位）。要判定"读档成没成"必须先用 `0x1A0` 验头。
- ★`i1a0` 的存在性探针（532-545）：状态读 `f7ffd`、槽号来自 `f8019`（= `0x3de + load-int 1390`）、其余 7 个输出全丢进**丢弃槽** `f7ffe` ⇒ 只关心「这个槽有没有存档」（`eq (global-int f7ffd) 0`）；全语料 334 处同型块（tickets/台账见 analysis/functions.json 的 0x42DC70）
- ★ADV 侧栏的稳定靠 `0x10A` 把光标**钉进栏内**（`i10a 4c4 (global-int 13a0)`）：`global 139f/13a0` = `read-mouse-pos` 的光标 X/Y，x=0x4c4=1220 在 T-0016 的侧栏条热点（0x49c..0x500）里；symmetric 的 `i10a 479`（1145）用于放出（tickets/T-0048；0x10A 语义见 analysis/functions.json 的 0x421EA0）
