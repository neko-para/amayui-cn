# UI 元素地图（工具 A）

把「猜坐标 → 逐点查询连通块」的人工定位循环，变成「一次扫描 → 浏览器里看图点选」。
**无 OCR、无 AI，纯几何（alpha 阈值连通块），100% 可复现。**

## 用法

```bash
python3 scripts/uimap/scan_blocks.py <png> [--alpha N] [--min-px N] [--out out.html]
```

- `--alpha`：前景阈值，默认 `128`（实体范围）；要含羽化边缘用 `1`。
- `--min-px`：过滤小于该像素数的碎块，默认 `300`。
- `--out`：输出路径；缺省为 `<png 同目录>/<名>_blocks.html`。

输出是**自包含 HTML**（图片 base64 内嵌），浏览器直接打开即可，无需服务器。

## 页面交互

| 操作 | 效果 |
|---|---|
| 悬停图上块 | 显示编号 / x、y 范围 / 宽高 / 像素数 |
| 点击图上块 | 选中 / 取消（金色框），右侧清单同步 |
| 右侧列表行 | 点击选中，悬停定位到图上 |
| 最小面积滑块 | 过滤碎块（默认取扫描时 --min-px） |
| 只显示选中 | 只看已勾选块 |
| 导出选中 JSON | 下载 `<名>_selected.json` |

块颜色按面积分级：橙 ≥100k px（大背景面板）、蓝 ≥3k px、绿 ≥500 px、灰更小。

## 导出 JSON 结构

```json
{
  "png": "SO020.png",
  "size": { "w": 1792, "h": 1280 },
  "alpha": 128,
  "min_px": 300,
  "selected_count": 22,
  "components": [
    { "index": 6, "x0": 1006, "x1": 1147, "y0": 6, "y1": 25, "w": 142, "h": 20, "px": 2634 },
    ...
  ]
}
```

`components` 里即为待处理元素清单，直接作为后续「清理工作台（工具 B）」的输入区域。

## 验证记录（res 图）

- `res/SO020.png`（1792×1280）：244 块，22 个按钮坐标与 `docs/images/SO020.md` 完全吻合。
- `res/SO017.png`（900×1280）：115 块，技能名文字块与 `docs/images/SO017.md` 公式坐标吻合。

## 备注

- 依赖仅 Pillow；Python 3.14 / Pillow 12.3 验证通过。
- 大图（2000×2000）全图扫描约 1-2 秒，HTML 自包含体积约等于原图 base64（3MB 图 → ~4MB HTML）。
- 后续工具 B（清理工作台）将消费本工具导出的 `components` 列表。
