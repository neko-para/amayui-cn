# 06 — 路线图与风险

## 0. 已确定的方向（用户拍板）

1. **静态 Web 应用为主**：可部署到 GitHub Pages，无宿主/后端/IPC 也能完整运行。
2. **无安装包**：桌面版（可选/后置）按 ZIP 便携分发，仅服务无法访问 GitHub 的场合，**不提前介入**。
3. **中文/日文搜索**：名称用 `src/` ITINIT/PLINIT/EBINIT 汉化（`日文|中文`）。
4. **规划器纯输入→输出**：无背包/持有量；**后置为独立模块**。
5. **独立 TS monorepo**：app 不与 `scripts/` 共享环境；提取脚本、类型与前端都放本工程内；数据**直接输出到 `public/data/metadata.json`**（衍生物，`public/` gitignored），`src/` 权威源。
6. **部署**：GitHub Pages 走**独立 deploy 分支**（CI 构建并提交 `dist/`）；主分支不提交衍生物。

## 1. 里程碑（主路径：数据提取 → 静态壳 → 查看/检索/联动跳转 → 部署；规划器后置）

| 里程碑 | 内容 | 交付物 / 验收 |
|---|---|---|
| **M0 数据提取 + 类型契约** | 在 app 内实现 `scripts/extract-metadata.mjs`（读 `src/`，归一化 + 中文名 + 校验），**直接输出**到 `public/data/metadata.json`；编写 `src/types/metadata.ts`、`src/types/nav.ts`（统一类型契约/抽象）。 | `public/data/metadata.json` 生成；计数与已知一致（923/113/458/243/203/648/252）；未汉化项计入；类型对齐。 |
| **M1 可运行 SPA 静态壳** | Vite+React+MUI+TS 跑通；`base:'./'`；`fetch` 载入数据；SPA 单视图 + 通用卡片容器 + 内存历史；`runtime.ts` 探测。 | `pnpm dev` 浏览器打开；搜索 + 卡片渲染 + 点击引用替换下半区 + 返回可用；`dist/` 本地预览。 |
| **M2 查看 / 检索 / 联动跳转（核心）** | 中/日双索引检索 + 卡片反查 + 详情；物品↔配方↔掉落互链跳转；未定语义徽标。 | 双索引可检索；反查正确；跨实体跳转顺畅；`vitest` 覆盖 `search`/`join`。 |
| **M3 发布** | `pnpm build` → `dist/`；GitHub Pages 走**独立 deploy 分支**（CI 构建并提交）；`runtime.ts` 决定是否启用壳能力。 | 静态页可公网访问；CI 发布就绪；README/CHANGELOG 就绪。 |
| **M4（后置/独立）制作规划器** | 依赖树 + 汇总 + 获取途径 + 防环；纯输入→输出；不可制作提示。 | 独立模块接入；多案例展开正确；环检测、汇总通过单测。 |
| **M5（后置）桌面薄壳 + ZIP** | 可选薄 WebView2 壳（推荐 Tauri 2 `--no-bundle`）打 ZIP；WebView2 运行说明。 | 解压即用；与静态版功能一致；仅服务无法访问 GitHub 者。 |

> 每期末尾用**真实数据抽查**（对照 `src/`）回归，避免“看对但数据假”。

## 2. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **`rate` 语义未定** | 掉落页可能误报 | 按“率/权重（未定）”带徽标展示；语义确认后补 `rateMeaning`，前端版本化兼容。 |
| **`recipes[].metadata` 语义未定** | 无法确定含义 | 详情页展示原始串 + 徽标；留待逆向 `AGE.EXE` 补齐。 |
| **物品/建筑 id 空间重叠**（如 id 51） | 产品名歧义 | `recipes[].productRef` 显式消歧；必要时增 `productItem`/`productBuilding`。 |
| **单位副标题地址区间**（`src` 多在 `17e` 区间，旧脚本判 `17f-181`） | 取 title 可能错位 | 本脚本沿用已验证判据；产出 `title`/`titleZh` 正确；完整性校验兜底。 |
| **未汉化项**（`nameZh===name`） | 中文搜索缺漏 | 回退日文名并标“未汉化”；随汉化进度重跑 `build:data` 自动补全。 |
| **多文件旧产物**（主工程 5 JSON）与新单文件并存 | 数据口径混乱 | 以 `public/data/metadata.json` 为真值；README 已标注；建议主工程旧文档后续对齐。 |
| **递归规划死循环 / 缺失材料** | 无限展开 | DFS 防环 + `cycle` 标记；叶子标来源；缺失流程提示（后置模块）。 |
| **前端 JSON 体积/启动** | 首屏慢 | 当前数 MB 无压力；增大则换 SQLite/懒加载分片。 |
| **GitHub Pages 子路径/发布** | 资源错位 / 衍生物污染主分支 | `base:'./'`（SPA 单视图无 404）；CI 只在 deploy 分支构建并提交 `dist/`，主分支不提交衍生物。 |
| **范围蔓延**（想做编辑器/翻译等） | 偏离“查询+规划” | 以《需求与范围》为准；新增走独立课题。 |

## 3. 决策记录

| # | 决策 | 结论 | 影响 |
|---|---|---|---|
| **D1** | 产物/宿主形态 | 核心 = 静态 Web 应用；桌面壳**可选、后置**（Tauri 2 便携构建），ZIP 分发、无安装包 | 桌面壳不提前做；主路径是 `dist/`。

| **D4** | 规划器边界 | 纯输入→输出，无背包；**后置** | 规划器不占主路径；依赖图设计保留。

## 4. 下一步建议

1. 进入 **M1**：`extract-metadata.mjs` 已产出 `public/data/metadata.json`（计数校验通过）。搭 Vite+React+MUI **SPA**：顶部搜索 + 下半通用卡片容器 + 内存历史（`navigate/goBack`），先跑通浏览器版（兼做 GitHub Pages 基线）。
2. **M2** 完善检索/反查/联动跳转 + 未定语义徽标；补 `vitest`。
3. **M3** 接 GitHub Pages 的 deploy 分支发布；桌面壳与规划器**后置**，待主路径稳定后再补。
