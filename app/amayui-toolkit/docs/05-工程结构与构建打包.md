# 05 — 工程结构与构建打包

> 本工程是**独立 TS monorepo**（不与 `scripts/` 共享环境）。**主路径 = 静态 SPA 应用（GitHub Pages）**；桌面薄壳为**可选、后置**，仅用于无法访问 GitHub 的场合，**不提前介入**。

## 1. 目录树

```
app/amayui-toolkit/                 # 独立 monorepo（当前单体包）
├─ package.json                     # type:module；scripts.build:data = node scripts/extract-metadata.mjs
├─ tsconfig.json                    # TS（strict）
├─ .gitignore                       # 忽略 public/、dist/、node_modules、src-tauri/target
├─ docs/                            # 本方案文档
├─ src/                             # 前端（React+MUI+TS）SPA
│  ├─ types/
│  │  ├─ metadata.ts                # ★ 元数据统一类型契约（TS-first）
│  │  └─ nav.ts                     # ★ CardSpec / View（数据抽象，供渲染容器/历史）
│  ├─ dataset/                      # 载入 metadata.json → 建索引/图
│  ├─ store/                        # zustand（dataset / view / 内存历史 / theme）
│  ├─ components/
│  │  ├─ CardList.tsx               # 通用渲染容器（下半区）：按 CardSpec 映射到卡片
│  │  ├─ cards/                     # ItemCard / UnitCard / BuildingCard / RecipeCard / MessageCard
│  │  ├─ SearchBar.tsx              # 顶部搜索（Autocomplete，日/中）
│  │  └─ RefChip.tsx                # 可点“引用”→ navigate（替换下半区）
│  ├─ services/                     # 纯 TS 领域层（search / planner(后置) / join）
│  ├─ runtime.ts  main.tsx  App.tsx  theme.ts
├─ scripts/
│  └─ extract-metadata.mjs          # ★ 读 工程根/src → public/data/metadata.json（ESM，node 直接跑）
├─ public/
│  └─ data/
│     └─ metadata.json              # 衍生物（gitignored）：前端 fetch('./data/metadata.json')
├─ src-tauri/                       # 可选桌面薄壳（WebView2，后置）
│  ├─ Cargo.toml  src/{main,lib,commands}.rs  capabilities/default.json  icons/
├─ dist/                            # Vite 产物（上 GitHub Pages -> deploy 分支）
└─ tests/                           # vitest 单测（领域层）
```

> `public/data/metadata.json` 是**衍生物**（`public/` 已 gitignore）：由 `extract-metadata.mjs` 从 `src/` 直接生成，供本地调试；GitHub Pages 由 **deploy 分支**在 CI 构建生成，主分支不提交。

## 2. 脚手架与依赖

```bash
# 前端（在 app/amayui-toolkit 下）
pnpm add react react-dom @mui/material @emotion/react @emotion/styled @mui/icons-material zustand
pnpm add -D vite @vitejs/plugin-react typescript @types/react @types/react-dom vitest
# 可选：仅当补桌面壳
pnpm add -D @tauri-apps/cli && cargo install tauri-cli --version ^2
```

> 提取脚本为纯 ESM JS（无第三方依赖），Node 直接运行，无需 TS 编译链；类型契约为 `src/types/*.ts`（供前端）。

## 3. Vite 配置（GitHub Pages 友好）

```ts
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
export default defineConfig({ base: './', plugins: [react()], build: { outDir: 'dist' } });
```

- **SPA 单视图**（局部状态驱动，无 URL 路由，故无 404 问题）；若后续做可分享链接，用 `window.location.hash` 序列化视图。
- `public/data/metadata.json` 由 Vite 原样拷入 `dist/data/`；前端 `fetch('./data/metadata.json')` 异步载入，**不经 bundler `import`**（数据与代码解耦，换数据无需重打包 JS）。

## 4. 脚本与数据流

`package.json` scripts：

```jsonc
{
  "build:data": "node scripts/extract-metadata.mjs",   // src → public/data/metadata.json（衍生物）
  "build:web":  "vite build",                          // dist/
  "build":      "pnpm build:data && pnpm build:web",
  "dev":        "pnpm build:data && vite",
  "preview":    "vite preview",
  "test":       "vitest run",
  "desktop:build": "pnpm build && tauri build --no-bundle"   // 仅后置；产出目录供打 ZIP
}
```

> 数据流：`工程根/src` → `extract-metadata.mjs` → `public/data/metadata.json`（衍生物）→ 前端 `fetch('./data/metadata.json')`。

## 5. 部署（GitHub Pages：独立 deploy 分支，CI 构建）

| 产物 | 方式 | 说明 |
|---|---|---|
| **静态版（主路径）** | CI（deploy 分支/workflow）：`pnpm build` 生成 `dist/` → 提交到 **deploy 分支**（`gh-pages` 或 Actions 发布） | 纯静态、无后端/IPC；改 `src/` 触发重构建。 |
| **桌面版（后置/可选）** | `pnpm desktop:build` 产出目录 → 打 ZIP；用薄 WebView2 壳加载同一 `dist/` | 仅服务无法访问 GitHub 的自用/分发；无安装包。 |

- **主分支不提交衍生物**：`public/`、`dist/`、`metadata.json` 均忽略；CI 在构建时重新生成数据再打包。本地 gitignore 仅为调试便利。
- 桌面壳仅提供少量原生增强（保存框/打开目录），经 `runtime.ts` 的 `hasNative` 探测降级，不影响静态版。

## 6. 与主工程关系

- 本工程为独立子工程；构建期**只读**主工程 `src/`（`AMAYUI_SRC_DIR` 可覆盖）。
- 主工程旧的提取脚本（`scripts/extract-recipes.js`、`extract-unit-drops.js`）与旧 `metadata/` 多文件**已被本工程 `extract-metadata.mjs` + 单一 `metadata.json` 取代**；建议未来将主工程旧文档对齐到统一格式。

## 7. 测试策略

- 领域层 `services/{search,join,planner}.ts`：`vitest`（双索引检索、反查、递归展开、防环、汇总、join 完整性）。
- 数据管道 `scripts/extract-metadata.mjs`：含校验断言 + 计数核对，输出 schema 快照对比防漂移。
- UI：手动为主；可加 Playwright 对静态版冒烟（浏览器模式，兼顾 GitHub Pages 场景）。
