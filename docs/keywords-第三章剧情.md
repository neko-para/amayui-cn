## 3. 剧情脉络

1. 米克修亚娜（马兹忒利亚神殿征炎众第六位）拜访菲优希亚神殿，与大司教库德万斯会谈三件事：
   信徒减少、『可移动城砦』（被指为世界禁忌）、进入神响霞廊（被拒）；
2. 城砦侧：阿瓦罗召集众人商定新方针（人手增加→多赚钱、强化装备以应对战斗）；
3. 罗兹利奴向吉尔什汇报城砦调查（菲亚操纵城砦、力量蓄满即移动、以他人悲痛使她无法集中），
   吉尔什借出灵体干扰城砦；
4. 米克修亚娜造访雷府云海，与绝冰公卡尔梅尔格会面（先代族长希乌凯托尔亡故、继承未定），
   接下『破坏城砦』委托；
5. 卡特利特（巫童/先代遗孤）因未觉醒力量遭绝冰公羞辱与加害，随侍蜥龙兵拼死掩护其逃出雷府，
   临终叮嘱她"逃到远方"；
6. 卡特利特在雨中密林独自逃亡，忆起蜥龙兵遗言，决定"去远方"。
