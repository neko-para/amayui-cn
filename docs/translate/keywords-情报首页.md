## 3. draw-string 处理约定

- `draw-string <纹理> <x> <y> <文本>`：前 3 个操作数（绘制参数）不动，尾参字面量用对语法译出；
- 尾参为寄存器/全局字符串引用时不译（源表已译）；
- 符号类（`/`、`％`、`×`、`∞` 等）保持原样；
- 控件文本不适用 ≤25 字/行规则，但需注意控件绘制宽度。
