## 2. 约定与备注

1. 章节号：`Ｎ章→第Ｎ章`（SC0010 原译 第１章 已对齐为 第一章）；`終章→终章`；
2. 副标题专名复用既有定稿：双盾姬（莉秀恩兹利）、灵泄之途、军神（马兹忒利亚）、混沌之女神；
3. 涅（SC0190）：全工程仅此一处；「涅」在现代日语中几乎只见于「涅槃」，
   定为「亡者/彼岸」的暗喻，指该章已故的先代族长**希乌凯托尔**（卡特利特之父）——
   他在府幻龙骨堂以成竜之姿现身、托付武器后消失，正合「動き出す涅＝亡者苏醒」；
   译文定稿为「盈满之时　亡者苏醒」（2026-08-08 用户确认）；备用读音解读（ネ音→魔神布涅）
   因本章无布涅登场而不取；
4. 英文标题（SC0280 ｉｎｆｉｎｉｔｅ ｋｎｏｔｓ / ＬＡＳＴ ＩＭＰＲＥＳＳＩＯＮ）为全角拉丁原文，保留不译；
5. 上述 SC0070–SC0250 仅翻译了章节标题串，其余剧情仍未翻译（PROGRESS 中仍计为未翻译文件）。
