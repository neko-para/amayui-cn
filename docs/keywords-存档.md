## 1. 确认对话框

| 日文 | 中文 |
|---|---|
| ロードしますか？ | 要读取吗？ |
| セーブしますか？ | 要保存吗？ |
| 削除しますか？ | 要删除吗？ |
| 移動しますか？ | 要移动吗？ |
| コピーしますか？ | 要复制吗？ |
| 上書きしてよろしいですか？ | 确定要覆盖吗？ |
| はい / いいえ | 是 / 否 |

## 4. 术语口径

- セーブ/ロード → 保存/读取（OPINIT1 同：数据保存/数据读取）；
- オートセーブ/自動セーブ → 自动保存（OPINIT1「执行自动保存」一致）；
- 上書きセーブ → 覆盖存档（OPINIT1「覆盖存档时清除备注」一致）；
- アペンドデータ → 追加数据（工程文档中 APPEND 追加包数据的玩家向说法）。
