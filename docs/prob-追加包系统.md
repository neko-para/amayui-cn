## 4. 名词评估记录（2026-08-11）

- 眩耀の宝物庫（$3$AMINIT2 / $3$STINIT2 地点名）：原文**非强行拼凑**——「眩耀（げんよう）」是
  中日辞书都收录的文语词，义为「光彩夺目、闪耀」（中文「眩」通「炫」；日汉词典标（文））。
  直译「眩耀的宝物库」字面正确，但现代中文读者容易读成「炫耀」（贬义），且「眩」易联想眩晕。
  候选：耀眼的宝物库 / 眩目的宝物库。**未定稿**，现译暂保持「眩耀的宝物库」。
- 斡旋（$3$DPINIT 地图地点标签，训练对手介绍所）：
  评估（2026-08-11）：原文**非强行拼凑**——「斡旋」为中日共通词，无需额外翻译；
  但存在语义偏差：日文「斡旋」=介绍/安排/中介（如 就職斡旋），中文「斡旋」=调解/周旋，
  故「中介」在语义上其实更贴近日文原意；然而作为幻想风 UI 标签，「中介」带现代
  「房产中介」既视感，保留原文更贴游戏氛围。项目先例：基座 DPINIT 的「工房/商店」
  即中日同文、不带竖线保留原样。**已定稿：保留「斡旋」**（src 已还原为无竖线原文，
  find-untranslated 归为 same 类，无需处理）。
