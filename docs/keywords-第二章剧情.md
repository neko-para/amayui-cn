## 3. 剧情脉络

1. 序章·回忆：伊欧露买来魔法书赠给米凯优，两人相依为命（伊欧露做杀手、米凯优求职碰壁）；
2. 城砦北上至天枯断层附近（兽人族村落），女神力耗尽停下，决定与当地交流；
3. 吉尔什王子斥责姬斯尼尔未确保遗迹（报告会），谋划夺取城砦；
4. 伊欧露向盖达鲁请辞（因米凯优目睹杀人现场，不再行凶），盖达鲁软硬兼施后放行并另作打算；
5. 伊欧露击破上级恶魔救出米凯优；阿瓦罗与菲亚邀请两人入住城砦（成为家人）；
6. 盖达鲁趁城砦空虚潜入中枢，滴血认主失败（已有主），决意夺主之命。
