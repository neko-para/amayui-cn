## 1. 种族字段（已确认）

**`种族值 = 0x52a0b4 + 单位id`**（单位名 `0x17ab6 + id`，1-based；同一 per-unit struct）。

| 值 | 种族 | 例 |
|---|---|---|
| `0x1` | 人族 | キスニル、ディートヘルム |
| `0x2` | 亜人 | アヴァロ、イオル、ミケユ |
| `0x3` | 一般 | プテテット、牙コウモリ |
| `0x4` | 鬼 | 小鬼族、エーグ族 |
| `0x5` | 巨人 | トロエルグ（生物型） |
| `0x6` | 精霊 | 流燐結騎、鉄精、フィア＝イブラム |
| `0x7` | 天使 | ミクシュアナ、大天使 |
| `0x8` | 悪魔 | 歪魔デブラフスカ |
| `0x9` | 魔獣 | 葉魔獣 |
| `0xa` | 幻獣 | カトリト(竜)、角蜥蜴 |
| `0xb` | 霊体 | 霊虚二舞イ人ノ傀 |
| `0xc` | 不死 | 絶怨ノ皇子 |
| `0xd` | 創造 | 石巨人、旋風岩（非生物/魔像） |
| `0xe` | 魔神 | べリアル、フォルネウス |
| `0xf` | 特殊 | フィア、エウシュリーちゃん |

**交叉核对（与 DRINIT 的 `6c56c1 类型-种族`）**：DRINIT 训练所用到 `0x2..0xd`，其文案种族词 → 值与上表完全一致。基址扫描含种族词单位 `0x52a0b4` 命中率最高（82%）；余下为「职业词/魔像分类」特判（`精霊師`/=人族、`石巨人`/=創造），属正确分类。

## 2. 性别字段（本次确认）

**`性别值 = 0x52a49c + 单位id`**（与种族同一 per-unit struct，种族基址往前 24 字节）。

| 值 | 性别 | 分布 |
|---|---|---|
| `0x1` | 男 | 91 |
| `0x2` | 女 | 117 |
| `0x3` | 无性别 | 165 |

**验证证据**（全量 373 个单位 `0x52a49c+id` 都有值）：

1. **基址扫描评分**：0x52a49c 为所有覆盖≥90% 的 base 中性别评分最高的（+55），远超第二名（0x52b054 = −34）。
2. **名字含 姫/姬/王妃/女神/女/娘 的单位 10/10 = 女(2)**。
3. **鬼族 12/12 = 男(1)** —— 与「鬼族一般被视为男性」一致。
4. **創造类 78 个中 72 个 = 无性别(3)**（石像/魔像/机械/捕食箱）；少数「捕食箱」「バグクイーン」= 女，属游戏设定的变异体。
5. **独立锚点**：カトリト(女主角/龙)=女、フィア=女、アヴァロ=男、リリィ=女、ミクシュアナ=女。

**6 个训练单位（DRINIT 训练者）自身性别**：
0x32 流燐結騎=男、0x33 溶燐結騎=男、0x34 嵐燐結騎=女、0x35 華燐結騎=男、0x37 霊虚二舞イ人ノ傀=男、0x38 愛ヲ模リ咲ヒメル傀=女。

## 2b. 属性字段（本次确认）

**`属性值 = 0x52b054 + 单位id`**（与种族/性别同处 per-unit struct）。

| 值 | 属性 | 分布 |
|---|---|---|
| `0x1` | 物理 | 116 |
| `0x2` | 地脉 | 39 |
| `0x3` | 冷却 | 43 |
| `0x4` | 火炎 | 35 |
| `0x5` | 电击 | 54 |
| `0x6` | 神圣 | 22 |
| `0x7` | 暗黑 | 63 |

**识别方法**：以「天使→神圣(6)、不死/灵体→暗黑(7)」为锚，扫描所有 per-unit 字段的种族相关性，`0x52b054` 评分第一。

**验证证据**：

1. **用户种族锚点**：天使 13/15=神圣、灵体 12/13=暗黑、不死 15/23=暗黑、鬼 12/12=物理、创造 50/78=物理。
2. **值域恰为 `0x1..0x7`**，与 DRINIT 的「类型-属性」枚举（物理/地脉/冷却/火炎/电击/神圣/暗黑）**同构**（见 `06-训练所数据.md` §4a）。
3. **覆盖 372/373**（近满；邻域呈对称衰减，正是「满数组」特征）。
4. **训练单位自身属性符合设定**：流燐結騎=冷却(冰)、溶燐結騎=火炎、嵐燐結騎=电击、華燐結騎=地脉、双傀=暗黑。
5. 属性是**单位自家的，且非由种族唯一决定**（同种族可有多属性，如精霊 42 个 = 电击/地脉/冷却 各约 12）；种族只是主导倾向。

> ⚠️ **特殊空缺（保留空）**：单位 **`0xcb 係留係の神殿兵`**（系留系神殿兵）的种族(2/亜人)、性别(1/男) 都有值，唯独 `0x52b054+id` **无写入** —— 它自身在 `0x52a000..0x52b100` 整段没有任何 `mov`，属**模板/占位单位**（仅事件/剧情槽，非正规战斗单位），属性位在 `src/` 中**确为空白**。**非解析遗漏，如实留空**导出（CSV 该行属性列空）。相邻 `0xca フィユシア神殿兵`(属性=6 神圣) 可作为同体系参考，但不作推断补全。

- **注意**：属性 = 单位自身，与 DRINIT 的「类型-属性」条件**等价但读数不同**——DRINIT 的 `6c5789` 是**被消耗单位的属性门槛**；本字段是**单位自己的属性**（训练者与怪物都有）。

## 3. 语义澄清（**重要**）

DRINIT 训练所里的 6 个单位是**训练者**，不是被训练对象：

```
eq (local-int 0) (global-int f8c44) 32      ← 训练者单位 id（0x32 = 流燐结骑）
jcc (local-int 0) ffffffff label_00001ac0
…

set-string … "★３以上の鬼　×４"              ← 需要「消耗」满足条件的单位（种族/性别/等级/数量）
mov (global-int …) …                        ← 条件字段 + 奖励（技能等）
```

- **`类型-种族` / `类型-性别` / `类型-属性` / `等级` / `数量` / `前置要求`** 描述的是**被消耗单位**必须满足的条件。
- **`效果-技能`** 是训练奖励（授予训练者/相关单位的技能）。
- 因此这些字段**不是**训练者自身的属性；训练者自身的种族/性别/属性在 **EBINIT**（本文件 §1 / §2 / §2b）。
