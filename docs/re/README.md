# 天結いキャッスルマイスター — 逆向分析资料库（docs/re）

> 本目录是**逆向分析的下游沉淀**，按「分析对象」分成两个子目录，**严格区分**。早期散落在 `docs/` 根目录的逆向/数据提取文档（`地图内单位`、`单位掉落物`、`物品建筑配方`、`AGE脚本语言与物品数据结构`）已**全部并入本目录**（`re/src/09`、`re/src/03`、`re/src/10`、`re/engine/00`+`re/src/11`），`docs/` 根目录只保留**工程/流程**（README、font-build、AGERC对话框汉化）与**UI 图片汉化**（`images/`）、**汉化逻辑**（`translate/`）。
> - **[`docs/re/engine/`](./engine/README.md)** — **引擎（二进制/VM）本身的分析**：
>   针对 `raw/AGE.EXE` / `raw/天结_unpacked.exe` / `engine\*_utf8.c` / `engine\*_utf8.lst`（反汇编对象）。
>   内容：加壳判定与拆壳、通用解释器架构、字节码 opcode 分发机制、解释器主循环、引擎侧运行时数组。
>
> - **[`docs/re/src/`](./src/README.md)** — **src 层面数据（游戏脚本字节码 + data 静态表）的分析**：
>   针对 `src/*.txt`（反汇编脚本）、`data/*.txt`（静态数据表）、`SAVE*.DAT`、脚本调用图。
>   内容：`call-script` 索引→文件名、`jcc` 语义、掉落数据表结构、`rate` 语义、存档与内存扫描、技能表结构、训练所结构、单位种族与性别。
>
> 组织约定：
> - 两域各自的**事实性结论**放各自子目录；**跨域桥接点**（如引擎侧运行时数组 `0x53f48c`(恒 0/死判断)、`0x928a7`，以及战斗随机池 `0x5697a` 在掉落判定中的作用）在主归属域详述，另一域只做**交叉引用**，避免重复。
> - 结论都标注三级事实度：**已确认**（数据/反汇编实证） / **推测**（尚无定论） / **未解**（Todo）。
> - 涉及的文件路径一律指向工程内**真实路径**；引擎反汇编文件优先用 UTF-8 版本（`*_utf8.c` / `*_utf8.lst`）。

## 关键地址 / 索引速查

| 地址 / 索引 | 域 | 含义 |
|---|---|---|
| `0x1d4f4` | src | **技能名数组基址**（`skillId = 名串地址 − 0x1d4f4`；容量 1000）→ 见 `src/05` |
| `0x1d8dc` | src | `= 0x1d4f4 + 0x3e8`，技能**简述**数组基址（`0x1d8dc + skillId`） |
| `0x1dcc4` | src | `= 0x1d4f4 + 2*0x3e8`，技能**题头/详述**配对数组基址（`0x1dcc4 + 2*skillId` 与 `+1`，**2 槽/技能**） |
| `0x6c65a2` | src | 技能**数值字段**基址（字段主序：`0x6c65a2 + k*1000 + skillId`）；另有 5 槽 `0x6c84e2`、13 槽 `0x6d2cda` 二维子数组。语义未定 |
| `0x53e104` | src | 掉落 `rate` 数组合基址（`rate_addr = 0x53e104 + unitId*5 + 槽`） |
| `0x53cd7c` | src | 掉落 `item` 数组合基址 |
| `0x53f48c` | 引擎 + src | `= 0x53e104 + 5*1000`，id=1000 边界 + **下一段起点**；该区段**恒 0、项目未写**（`COMMITBTL` 中 `X<=Y` 为死判断）→ 见 `src/03`、`engine/04` |
| `0x928a7` | 引擎 + src | 引擎维护的每单位运行量；因 `0x53f48c` 恒 0，`X<=Y` 恒真，**其 Y 不参与本项目掉落判定** → 见 `engine/04` |
| `0x5697a` | 引擎 + src | **战斗随机池**（1000 项 = 0x32×0x14 = 50 行×20 列，值 0–99）；FIELD 用**嵌套循环 + `random 0x64` 指令**逐项填充（`random`=`rand()%0x64`=`%100`），读档/撤退用 `memcpy` 走 `0xeafe5` 持久化，计数器 `0x5b8af`（`%0x14`=20）存于 `0xa8b85` → 见 `src/03-掉落数据.md` §3、`engine/04`；**src 字面量为 16 进制** |
| `this + 0x0A509C` | 引擎 | opcode→handler 函数指针表基址（下标=opcode，上限 0x400） |
| `sub_412290` / `.text:00412290` | 引擎 | **解释器主循环**（读 opcode → dispatch → 推进 IP） |
| `sub_42C6E0` | 引擎 | **`mod`(0x54) opcode handler**（`param1 = param2 % param3`） |
| `sub_41BF50` / `sub_41C300` | 引擎 | **读 int / 读 float 操作数原语**（按 type 分支 + `DEC` 去混淆）见 `engine/05-操作数访问原语.md` |
| `sub_42B4B0` / `sub_42BA00` | 引擎 | **写 int / 写 float 操作数原语**（`ENC` 编码 = `DEC` 逆运算）见 `engine/05-操作数访问原语.md` |
| `sub_42AEA0` / `sub_418B90` | 引擎 | **地址/指针操作数原语**：`sub_42AEA0`=取操作数内存地址/指针（`operandAddress_42AEA0`），`sub_418B90`=把值写入指针型操作数槽（`writePointerOperand_418B90`）；为 `lea`(0x63)/`memcpy`(0x1B0) 的底座 |
| `sub_415640` | 引擎 | **`Command` 构造器**（初始化 dispatch 表：`this+0xA509C`，默认 `sub_418E30`） |
