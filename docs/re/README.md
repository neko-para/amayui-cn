# 天結いキャッスルマイスター — 逆向分析资料库（docs/re）

> 本目录是**逆向分析的下游沉淀**，按「分析对象」分成两个子目录，**严格区分**：
>
> - **[`docs/re/engine/`](./engine/README.md)** — **引擎（二进制/VM）本身的分析**：
>   针对 `raw/AGE.EXE` / `raw/天结_unpacked.exe` / `engine\*_utf8.c` / `engine\*_utf8.lst`（反汇编对象）。
>   内容：加壳判定与拆壳、通用解释器架构、字节码 opcode 分发机制、解释器主循环、引擎侧运行时数组。
>
> - **[`docs/re/src/`](./src/README.md)** — **src 层面数据（游戏脚本字节码 + data 静态表）的分析**：
>   针对 `src/*.txt`（反汇编脚本）、`data/*.txt`（静态数据表）、`SAVE*.DAT`、脚本调用图。
>   内容：`call-script` 索引→文件名、`jcc` 语义、掉落数据表结构、`rate` 语义、存档与内存扫描。
>
> 组织约定：
> - 两域各自的**事实性结论**放各自子目录；**跨域桥接点**（如引擎运行时数组 `0x53f48c`/`0x928a7` 在掉落门控中的作用）在主归属域详述，另一域只做**交叉引用**，避免重复。
> - 结论都标注三级事实度：**已确认**（数据/反汇编实证） / **推测**（尚无定论） / **未解**（Todo）。
> - 涉及的文件路径一律指向工程内**真实路径**；引擎反汇编文件优先用 UTF-8 版本（`*_utf8.c` / `*_utf8.lst`）。

## 关键地址 / 索引速查

| 地址 / 索引 | 域 | 含义 |
|---|---|---|
| `0x53e104` | src | 掉落 `rate` 数组合基址（`rate_addr = 0x53e104 + unitId*5 + 槽`） |
| `0x53cd7c` | src | 掉落 `item` 数组合基址 |
| `0x53f48c` | 引擎 + src | `= 0x53e104 + 5*1000`，id=1000 边界；引擎维护的运行时判定数组之一 |
| `0x928a7` | 引擎 + src | 引擎维护的每判定量（`COMMITBTL` 中与 `0x53f48c[b*5]` 比较） |
| `this + 0x0A509C` | 引擎 | opcode→handler 函数指针表基址（下标=opcode，上限 0x400） |
| `sub_412290` / `.text:00412290` | 引擎 | **解释器主循环**（读 opcode → dispatch → 推进 IP） |

| `sub_41BF50` / `sub_41C300` | 引擎 | **读 int / 读 float 操作数原语**（按 type 分支 + `DEC` 去混淆）见 `engine/05-操作数访问原语.md` |
