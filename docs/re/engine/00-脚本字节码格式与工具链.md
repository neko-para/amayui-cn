# 脚本字节码格式与反汇编工具链（engine）

> 级别：**已确认**（`data/*.txt` 反汇编文本 + `.BIN` 魔数实证 + 工具实测）。
> 本文档承接 `docs/README.md` §7.2 的「脚本格式」要点，并**取代**早期 `docs/AGE脚本语言与物品数据结构.md` 里的指令清单部分——那部分在引擎可反汇编后已被 [`06-opcode到handler映射表.md`](./06-opcode到handler映射表.md)（opcode→名称→handler 全量表）取代。

## 1. 脚本容器与文件体系

- `.BIN` 脚本头部魔数 **`SYS4450 `**（**4**=v4；新作/续作另见 `SYS5501`）。头部 = 魔数 + 6 个 u32 局部变量数 + 0x1C + 三张表（length/offset）。
- 指令流为 **AGE 字节码**；字符串位于数据表尾部，**`0xFF` 按位取反 + SJIS(CP932)** 存储，`0xFF` 结尾（v4）或 UTF-16（v5）。
- 容器：`SYS4INI.BIN`（全局索引，魔数 `S4IC450 `，TOC 为 LZSS）+ `DATA1-8.ALF` / `APPENDnn.ALF/.AAI`。
- 版本说明：v1.07 现行——游戏**直读松散文件（根目录 105 个 `.BIN`）**，与 ALF 内同名的 89 个 BIN 中 87 个内容不一致（含真实文本修正），故语料以**松散版**为准。

## 2. 反汇编 / 重汇编工具链

| 工具 | 用途 |
|---|---|
| `tools/eushully-decompiler/.../age-asm.exe` | Kelebek1 AGE 脚本反汇编 `-d` / 重汇编 `-a` / 往返校验 `-x`（本作 SC0000.BIN 等逐字节 equal） |
| `tools/alf/unpack_alf.exe` | 解 `SYS4INI.BIN`+`DATA*.ALF`、`APPEND*.AAI`（LZSS 解 TOC） |
| `tools/alf/packdata`（源码） | 修改文件重打包进 ALF 并重建索引（待适配） |
| `scripts/alf/unpack_alf.mjs` + `lzss.mjs` | Node 版解包（`SYS4INI.BIN` 文件表） |

反汇编输出 UTF-8 文本；文本抽取正则（上游 SExtractor）：`show-text 0 "…"` / `display-furigana 0 "…" "…"` / `set-string (…) "…"`。

## 3. 指令模型（opcode）

- 每条指令 = opcode + 若干**typed 操作数**（type, u32）；参数按 **argc** 推进（`指令长度 = 4 + 8×argc`）。
- **opcode 的权威语义与本文档引擎 handler 见 [`06-opcode到handler映射表.md`](./06-opcode到handler映射表.md)**（544 条具名/函数实现；`random`(0x60)/`lea`(0x63)/`memcpy`(0x1B0) 等已由引擎反汇编解析确认）。
- **讲解**：解释器主循环 `sub_412290` 经一维函数指针表 `this+0x0A509C+4*opcode` 分发（见 [`03-opcode分发与解释器.md`](./03-opcode分发与解释器.md)）；操作数读/写原语见 [`05-操作数访问原语.md`](./05-操作数访问原语.md)。
- **文本相关指令**（汉化关注）：`set-string`(0x192)、`concat`(0x193)、`show-text`(0x6E)、`end-text-line`(0x6F)、`display-furigana`(0x196)、`wait-for-input`(0x72)、`draw-string`(0x204)。
