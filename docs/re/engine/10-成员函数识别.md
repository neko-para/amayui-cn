# Engine 成员函数识别（detection only）

> 级别：**已实现 / 可运行**（libclang + brew libclang dylib，纯文件驱动，无 IDA）。
> 脚本：`scripts/re/detect_members.py`；结果清单：`docs/re/engine/member_functions.detected.txt`（**959** 个 `sub_` 成员函数）。
> 前置：`09-clang解析与重定型基座.md`（prep + prelude 让 clang 能解析 Hex-Rays 输出）。

---

## 任务：识别「操作 Engine 的成员函数」，只输出函数名（不做替换）

### 1. 从高偏移定位「基准」（baseline seed）

某函数若存在一个**形参**（通常首参，即 `this`/`_this`）被以 **高偏移** 访问：

- 常数下标 `p[K]` 且 `K*elem` 命中 Engine 顶层字节偏移（`_this[95744]`→`global_int_base`，`_this[95776]`→`cur_script`，`_this[97059]`→`key`…）；
- 或 `p + <byteconst>` 命中（`a1 + 383104`→`cur_script`）。

则该形参确证承载 Engine，函数即 Engine 成员（`engine_params` 记录该形参）。

### 2. 搜索调用/被调用点（图传播，双向 taint）

沿调用图把「Engine this 值」传播开：

- **DOWN**：已知成员 F 调用 G，且把「Engine this 值」作为 **第 0 个实参** ⇒ G 的第 0 个形参也是 Engine ⇒ G 为成员。
- **UP**：某函数把「其 own this 值」作为实参传给一个已知成员（其第 0 形参为 Engine）⇒ 该调用方也是成员。
- 迭代到不动点（≤200 轮）。

### 3. 关键正确性处理

- **`(T)this` 强转**：`core_expr` 剥离前导 `(TYPE*)`/括号，`(_DWORD *)_this` → `_this`，使传播认出 this 值。
- **局部派生**：`v = this` / `v = _this[...]` 后 `sub(v,...)`，通过「赋值链 taint」把局部变量纳入 this 值集合。
- **clang 错误恢复丢弃函数体**：某些函数体（含类型不安全代码）未被 clang 挂上 body（`is_definition()==False`）。
  处理：把**所有 FUNCTION_DECL** 纳入函数表（同名优先带 body 者），无函数体的函数仍可被**传播**标出
  （如 `sub_40ED40`、`sub_405640` 由 `sub_41C6A0`/`sub_415640` 传入 `this` 而命中）。

### 4. 结果

- 输入 `hexrays_prep.py` 产出的 `/tmp/_prep.c`；输出 `--out` 写函数名清单。
- 命中 **959** 个 `sub_*` 成员函数；关键函数全部在列：
  `sub_41BF50` `sub_41C300` `sub_41A820` `sub_40ED40` `sub_405640` `sub_40FB60` `sub_40FC90`
  `sub_412290` `sub_415640` `sub_41C6A0` `sub_41A000` `sub_42B4B0` `sub_42BA00` …
- 少量误报（`sprintf_s`/`_CxxThrowException` 等 CRT/extern 经 argv[0] 传播进来）已过滤为仅 `sub_*`。

## 用法

```bash
VENV=pyenv/bin/python
python3 scripts/re/hexrays_prep.py engine/天结_unpacked.exe_utf8.c > /tmp/_prep.c
$VENV scripts/re/detect_members.py /tmp/_prep.c --out /tmp/_members.txt   # 输出全部成员函数名
```
