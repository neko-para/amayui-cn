## 1. 固定句式

| 日文原文 | 中文译文 | 说明 |
|---|---|---|
| ～を造ろう | 建造『…』吧 | 设施/工房建造（造ろう 一般译“建造”） |
| ～を作ろう | 制作『…』吧 | 道具/物品制作 |
| ～へ行こう / へ向かおう / へ行ってみよう | 前往『…』吧 / 去『…』看看吧 | 移动引导 |
| 女神ランク『Ｎ』を目指そう | 以女神等级『Ｎ』为目标吧 | 女神等级（BIINIT 口径） |
| ～を解放しよう / を探そう / を調査しよう | 解放『…』吧 / 寻找『…』吧 / 调查『…』吧 | 事件引导 |
| ～に備えよう / 準備をしよう | 为…做准备吧 | 备战引导 |
