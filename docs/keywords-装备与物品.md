1. **レイシア**：全部装备系列（ソード/メイル/シールド/チャクラ…）与连携名需统一，当前暂用「雷西亚」。
2. **骨斬包**：语义为「斩骨用身幅大的万能菜刀」，建议译「斩骨包」，需与装备任务核对（候选：斩骨刀）。
3. **イザヤ**：古预言者，装备「イザヤアルマトラ/イザヤグリーブ」词根，当前暂用「伊扎亚」。
4. **技能/状态**：技回/疲回/看破/狂暴化/大物杀手/痛击/会心/冷却/灼烧/剧毒/恐惧/激昂等均为本次建议，
   待 ILINIT/BIINIT/SKINIT 任务定稿后需回改 OFINIT/ITINIT。
5. **魅了 → 魅惑**：与形容词「魅惑」同译，若技能任务采用「魅了」则需全局回改。
6. **魔術 vs 魔法**：当前按原文区分（魔術師/魔術結界=魔术；魔法攻撃/魔法铠=魔法），需技能任务确认。
7. **レイシア系武器音译**：パルフェ/バウセス/クォレル/ガフェル/ガルガン/グレイプ/チャクラ 等专名待定。
8. **パール/アルブネア/コルシノ/ギグルン钢** 与 **爬龙/刃爬龙** 等词根译名待定。
