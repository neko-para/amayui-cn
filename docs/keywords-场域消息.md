## 4. F 组重排说明（方案①）

原顺序 `【分类】→道具名→を→N→個手に入れた！`；交换「道具名」与「を」两条 concat 后为
`【分类】→获得→道具名→N→个！`，成品与 CDINIT2「【素材】获得…１个」一致。
仅重排 concat 行，未动任何 lookup-array（骨架校验通过）。
