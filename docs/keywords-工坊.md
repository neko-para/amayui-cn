## 3. 处理说明

- concat 组装按 FIELD 先例用 `@"译文"` 字面量；「制作/炼成/获得」动词前置，重排字面量位置，
  `(local-string …)` / `(local-ptr …)` 寄存器保持不动；
- draw-string 字面量仅 "/"、"("、")"、"--" 等 UI 符号，语言中立未译；
- 本脚本无 ADV 页，不涉及 `// 输入原文` / `// 页面结束` 三段式。
