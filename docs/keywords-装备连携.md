## 4. 固定表述与格式约定

| 日文原文 | 中文译文 | 说明 |
|---|---|---|
| 装備リンク | 装备连携 | 全部标题前缀 |
| 組み合わせＡ～Ｆ | 组合Ａ～Ｆ | 保留全角字母 |
| すべての装備を外した状態で… | 卸下所有装备的状态下… | すっぴん/ノーガード共用 |
| 武器のみで戦う型　防御を考えず攻撃に集中する | 仅凭武器战斗的型，不考虑防御，专注攻击 | 武器使系列共用 |
| 最大ＨＰ / 最大ＳＰ | 最大ＨＰ / 最大ＳＰ | 保留全角 ＨＰ/ＳＰ |
| ～スキル付与 / ～効果付与 | 付与『…』技能 / 付与『…』效果 | 统一动词 |

## 5. 待联合检查事项

1. **レイシア**：全部装备系列（レイシアソード/メイル/シールド…）与连携名（レイシアの虜/レイシアマニア）需统一，当前暂用「雷西亚」。
2. **骨斬包**：语义为「斩骨用身幅大的万能菜刀」，建议译「斩骨包」，需与装备任务核对（候选：斩骨刀）。
3. **イザヤ**：古预言者，装备「イザヤアルマトラ/イザヤグリーブ」词根，当前暂用「伊扎亚」。
4. **技再/疲再**：本次按「技回」处理（技再Ⅲ=ＳＰ６回復），疲再未在 OFINIT 出现；需与 ILINIT/BIINIT 状态任务统一。
5. **見切り/凶暴化/大物殺し/痛打/冷却**：本次译文已在 §2 标注候选，技能任务定稿后需回改 OFINIT。
6. **魅了 → 魅惑**：与形容词「魅惑」同译，若技能任务采用「魅了」则需全局回改。
