## 3. 清理方案（用户导出配置，2026-08）

清理脚本 `.tmp/SO002-0_clean.sh`（链式，最终 `.tmp/SO002-0_clean_2.png`）：

| 块 | 区域 | keep-l | keep-r | keep-t | keep-b | fill-col |
|---|---|---|---|---|---|---|
| #3 (块 A) | x[274,427] y[50,97] | 36 | 35 | 0 | 0 | **313** |
| #4 (块 B) | x[277,398] y[101,129] | 21 | 20 | 0 | 0 | **300** |

> **关键点**：fill-col 移到**文字区左侧的干净背景**（块 A=313，文字区前；块 B=300，文字区前），
> 而不是字符间隙（如 350）。字符间隙列会混入相邻笔画左上边缘的**边缘插值/阴影**，复制后横穿文字区形成黑线。
> 外移 fill-col 后，文字区背景纯净，且真实按钮 bevel（上部 y=60 横带、下部斜向 bevel）自然衔接。
> 校验：改动全部落在两块矩形内（块外 diff=0）。

## 4. 渲染参数（E2 块 A / E3 块 B，复用 SO021/SO025/SO030 菜单块样式）

- **字体**：**Sarasa Gothic SC**（渲染页必须 @font-face 引用本地 `res/fonts/SarasaGothicSC/*.ttf`，防 headless 拉丁 fallback）；20px、letter-spacing 1px、居中、white-space:nowrap。
- **块 A**（E2 纯色底黑字）：`left:274px; top:50px; width:154px; height:48px; line-height:48px; color:#000; -webkit-text-stroke:0.5px #000;`（垂直居中于块高 48px）。
- **块 B**（E3 渐变底黑字+半透明白边）：`left:277px; top:102px(=y0+1, 下移1px); width:122px; height:29px; line-height:29px;` 双层兄弟节点：`.in`（`-webkit-text-stroke:0.5px #000; color:#000;`）+ `.out`（`-webkit-text-stroke:2px rgba(255,255,255,0.5); color:rgba(255,255,255,0.5);`）。

## 5. 渲染与合成

- 采用**两段式**：headless Chrome 只渲染「菜单」文字层（画布 640×256 透明底，`--default-background-color=00000000`，`--force-device-scale-factor=1`）→ `text_layer.png`；
  再用 `PIL Image.alpha_composite` 将文字层合成到清理后底图 `.tmp/SO002-0_clean_2.png`。
  > 这样背景不由 Chrome 重编码（避免整图截图的 ±1-3 RGB 颜色散），保证块外像素**逐像素保留**。

## 7. 复现命令

1. 清理（用户导出脚本）：
   ```bash
   python scripts/uimap/clean_fill.py 'res/images/SO002-0.png' '.tmp/SO002-0_clean_1.png' --x0 274 --y0 50 --x1 427 --y1 97 --keep-l 36 --keep-r 35 --keep-t 0 --keep-b 0 --fill-col 313
   python scripts/uimap/clean_fill.py '.tmp/SO002-0_clean_1.png' '.tmp/SO002-0_clean_2.png' --x0 277 --y0 101 --x1 398 --y1 129 --keep-l 21 --keep-r 20 --keep-t 0 --keep-b 0 --fill-col 300
   ```
2. 渲染文字层（headless Chrome，需提权）→ `.tmp\ui-redraw\SO002\text_layer.png`。
3. PIL 合成：`Image.alpha_composite(cleaned, text_layer)` → `res\images\SO002-1.png`。
4. AGF 注入：
   ```bash
   node scripts/agf/cli.js inject "install/DATA1/SO002.AGF" "res/images/SO002-1.png" -o "install/SO002.AGF"
   ```
5. 复制 `install/SO002.AGF` → `res/images/SO002.AGF` 与 `patch/AGF/SO002.AGF`；`npm run sync-patch`、`npm run manifest -- SO002.AGF`。
