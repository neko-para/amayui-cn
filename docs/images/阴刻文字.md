`text-shadow` 本质上只能生成字形外部阴影，并不支持真正的 `inset`。把背景色和阴影色互换只是视觉模拟；一旦需要半透明 fill，颜色层被提前混合，就无法保持独立 alpha。

更合适的方案是把三个部分分层：

1. 半透明灰色 fill；
2. 根据字形 alpha 生成的内部阴影；
3. 最上层单独绘制颜色 A 的 stroke。

推荐使用 SVG filter。它可以让 fill、inner shadow 和 stroke 保持独立。

```html
<svg class="engraved-text" viewBox="0 0 500 120">
  <defs>
    <filter
      id="inner-shadow"
      x="-10%"
      y="-10%"
      width="120%"
      height="120%"
      color-interpolation-filters="sRGB"
    >
      <!-- 半透明填充 -->
      <feFlood
        flood-color="#888"
        flood-opacity="0.35"
        result="fillColor"
      />
      <feComposite
        in="fillColor"
        in2="SourceAlpha"
        operator="in"
        result="fill"
      />

      <!--
        将字形 alpha 向右下移动。
        原字形减去移动后的字形，得到左侧和上侧的内边缘。
      -->
      <feOffset
        in="SourceAlpha"
        dx="3"
        dy="3"
        result="shiftedAlpha"
      />
      <feComposite
        in="SourceAlpha"
        in2="shiftedAlpha"
        operator="out"
        result="innerEdge"
      />

      <!-- 柔化内阴影 -->
      <feGaussianBlur
        in="innerEdge"
        stdDeviation="1.5"
        result="softEdge"
      />

      <!-- 保证阴影不超出字形 -->
      <feComposite
        in="softEdge"
        in2="SourceAlpha"
        operator="in"
        result="innerMask"
      />

      <!-- 给内阴影着色 -->
      <feFlood
        flood-color="#000"
        flood-opacity="0.8"
        result="shadowColor"
      />
      <feComposite
        in="shadowColor"
        in2="innerMask"
        operator="in"
        result="shadow"
      />

      <!-- 阴影覆盖在半透明 fill 上 -->
      <feMerge>
        <feMergeNode in="fill" />
        <feMergeNode in="shadow" />
      </feMerge>
    </filter>
  </defs>

  <!--
    这里必须使用不透明 fill 生成完整 SourceAlpha；
    实际灰色和透明度由 filter 中的 feFlood 控制。
  -->
  <text
    class="text-fill"
    x="20"
    y="85"
    filter="url(#inner-shadow)"
  >
    阴刻文字
  </text>

  <!-- stroke 单独绘制，避免被 filter 和透明 fill 混合 -->
  <text
    class="text-stroke"
    x="20"
    y="85"
  >
    阴刻文字
  </text>
</svg>
```

```css
.engraved-text {
  width: 500px;
  max-width: 100%;
  overflow: visible;
}

.text-fill,
.text-stroke {
  font: 700 64px/1 sans-serif;
}

.text-fill {
  /* 只用于生成完整的字形 alpha，最终不会直接显示 */
  fill: #fff;
}

.text-stroke {
  fill: none;
  stroke: #e29a35; /* 颜色 A */
  stroke-width: 2px;
  stroke-linejoin: round;
  paint-order: stroke;
}
```

### 参数调整

```xml
<feOffset dx="3" dy="3">
```

虽然偏移方向是右下，但进行“原字形减去偏移字形”后，留下的是左侧和上侧内边缘。

- 增大 `dx/dy`：阴刻区域更宽；
- 增大 `stdDeviation`：阴影更柔和；
- 修改灰色 `flood-opacity`：控制 fill 的真实 alpha；
- 修改黑色 `flood-opacity`：控制内阴影浓度。

如果需要右侧和下侧阴影，则把偏移改为负值：

```xml
<feOffset dx="-3" dy="-3">
```

关键点是不要给整个 `<text>` 或 `<svg>` 设置 `opacity`，否则浏览器会先把 fill、阴影、stroke 合成为一个离屏图层，再统一降低透明度。应该分别使用 `flood-opacity`、`fill-opacity` 或 `stroke-opacity`。

纯 CSS 目前没有跨浏览器的文字内阴影能力。理论上可以用重复文字、`mask-composite` 和伪元素构造，但需要复制文本内容，而且 Safari/Chromium 的 mask 合成语法存在差异。对于需要保留 fill alpha 的这种效果，SVG filter 通常是最稳定的实现。
