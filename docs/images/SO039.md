### 3.2 渲染参数（用户逐步确认的最终值）

- 字体：**Sarasa Gothic SC**（`res\fonts\SarasaGothicSC\SarasaGothicSC-Regular.ttf`，渲染页 @font-face 钉住本地），**24px**，字距 1px。
- 定位：`text-align:center` + `line-height:<块高>px`（块高 = 按钮高度）水平垂直居中；**`top = y0`（无上移——用户要求移除既有的 1px 上移与 `translateY(-0.5px)`）**。
- 列 1（#43/#58）：E5 **上半**（黑字 `#000` + 0.5px 黑描边；白描边 4px 100% + 阴影 `0 4px 4px rgba(0,0,0,1)` 于描边层）。
- 列 2（#48/#60）：E5 **下半**（黑字 `#000` + 0.5px 黑描边；白描边 4px 50%，无阴影）。
- 列 3（#44/#59）：**上白下浅绿两段式 + 原图深绿描边 + 黑色下阴影**（三层 span）：

```css
/* 列3（三层，z 分层） */
.shd  { position:absolute; left:0; right:0; top:0; z-index:0; color:#fff;
        -webkit-text-stroke:3px #fff;                 /* 字形剪影（含描边范围） */
        text-shadow:0 4px 4px rgba(0,0,0,1); }        /* 参考列1的黑色下阴影 */
.gout { position:absolute; left:0; right:0; top:0; z-index:1;
        color:transparent; -webkit-text-stroke:3px #015514; }   /* 原图深绿描边 */
.gin  { position:absolute; left:0; right:0; top:0; z-index:2;
        -webkit-text-stroke:0;
        background:linear-gradient(to bottom, #FFFFFF 0%, #FFFFFF 50%, #CDFDCD 50%, #CDFDCD 100%);
        -webkit-background-clip:text; background-clip:text; -webkit-text-fill-color:transparent; }
/* 按钮结构：<span class="shd">锁定</span><span class="gout">锁定</span><span class="gin">锁定</span> */
```

- 列 3 两色来源：对原图字形采样——**上端基本纯白 `#FFFFFF`**（经用户确认，非渐变而是两段式平铺）、**下端浅绿 `#CDFDCD`**；深绿描边取原图字形 `(1,85,20)`≈`#015514`。阴影参考列 1 E5 上半的 `0 4px 4px rgba(0,0,0,1)`。
