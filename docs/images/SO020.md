### 7.4 渲染 HTML 核心代码（可复现）

`<span class="in">`（红字层）与 `<span class="out">`（描边层）**并列**放置（兄弟节点，非嵌套）。
两 span 均 `position:absolute; left:0; right:0; top:0` 撑满按钮宽度、`z-index` 分层
（`.in` z=2 在上、`.out` z=1 在下），配合 `.btn` 的 `text-align:center` + `line-height:73px` 居中。

```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<style>
  @font-face { font-family: "WenQuanYi"; src: url("../res/fonts/WenQuanYi.ttf"); }
  html, body { margin: 0; padding: 0; width: 1792px; height: 1280px; background: transparent; overflow: hidden; }
  #bg { position: absolute; left: 0; top: 0; }
  .btn { position: absolute; width: 213px; text-align: center; line-height: 73px;
         font-family: "WenQuanYi"; letter-spacing: 1px; white-space: nowrap;
         transform: translateY(-0.5px); }
  .out { position: absolute; left: 0; right: 0; top: 0; z-index: 1;
         -webkit-text-stroke: 4px rgba(255,255,255,1); color: rgba(255,255,255,1);
         text-shadow: 0 4px 4px rgba(0,0,0,1); }
  .in { position: absolute; left: 0; right: 0; top: 0; z-index: 2;
        color: #FD480A; -webkit-text-stroke: 0; }
</style>
</head>
<body>
  <img id="bg" src="SO020_clean_4.png">
  <div class="btn" style="left:114px; top:778px; font-size:28px;"><span class="in">探索开始</span><span class="out">探索开始</span></div>
  <div class="btn" style="left:330px; top:778px; font-size:30px;"><span class="in">出击</span><span class="out">出击</span></div>
  <div class="btn" style="left:114px; top:853px; font-size:28px;"><span class="in">探索开始</span><span class="out">探索开始</span></div>
  <div class="btn" style="left:330px; top:853px; font-size:30px;"><span class="in">出击</span><span class="out">出击</span></div>
</body>
</html>
```

> 踩坑：`.in` 必须显式 `-webkit-text-stroke: 0` 或与 `.out` 并列放置（`-webkit-text-stroke` 会继承，
> 嵌套时红字会被父层 4px 白描边完全盖住 → 全白）。
