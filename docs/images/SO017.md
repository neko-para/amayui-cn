**最终样式（用户确认，完整 CSS）**：

```css
/* 字号 22px，WenQuanYi，行高 1；定位 transform: translate(-50%,-50%)，left/top 即中心坐标 */
.ln {
  position: absolute;
  font-family: "WenQuanYi";
  font-size: 22px;
  line-height: 1;
  white-space: nowrap;
  transform: translate(-50%, -50%);
}
/* ① 阴影层（最底）：基于描边字型；WebKit 中 text-shadow 绘制于 text-stroke 之上，须独立成层 */
.sh {
  position: absolute; left: 0; top: 0;
  color: transparent;
  -webkit-text-stroke: 2px #C90000;      /* 让阴影字型含描边外扩（透明色不影响形状） */
  text-shadow: 2px 2px 2px rgba(0,0,0,1);
}
/* ② 描边层：2px 红，内层覆盖内侧 → 露出外侧 1px */
.out {
  position: relative; display: inline-block;
  color: transparent;
  -webkit-text-stroke: 2px #C90000;
}
/* ③ 渐变文字层（纯纵向渐变，横向颜色一致）；必须清零描边防止继承 */
.in {
  position: absolute; left: 0; top: 0;
  -webkit-text-stroke: 0; -webkit-text-stroke-width: 0;
  background: linear-gradient(to bottom,
              #FEFE13 0%, #FEFEFD 38%, #FEFEFD 62%, #FEFE13 100%);
  -webkit-background-clip: text; background-clip: text;
  -webkit-text-fill-color: transparent;
}
```

```html
<div class="ln" style="left:CX;top:CY;">
  <span class="sh">中文</span>
  <span class="out">中文<span class="in">中文</span></span>
</div>
```

**样式要点**：
- 渐变：纯纵向 `#FEFE13 → #FEFEFD(中心白段 38%-62%) → #FEFE13`，横向颜色一致
- 描边：双层 span，外层 2px `#C90000`；内层渐变文字覆盖内侧 1px，仅露出外侧 1px
- 内层必须显式 `-webkit-text-stroke: 0`（该属性可继承，否则内层重画描边盖住渐变）
- 阴影 `2px 2px 2px` 纯黑：因绘制顺序在 stroke 之上，必须放独立 `.sh` 底层，且字型含描边外扩
- 阴影偏移调整历史：3px 3px 2px → 2px 2px 2px（用户确认）
