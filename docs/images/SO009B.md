## 8. 第一列（outline）阴刻渲染方案（2026-08，进行中）

第一列 outline 样式（主体棕褐 + 深色阴影，阴刻效果）尚未最终渲染。已确定方案：**SVG filter 三层独立合成**（fill / 内阴影 / stroke），见 `docs/images/阴刻文字.md`。

### 8.1 已确认参数

- 字号 28px（bold），行高 30px（第一列行距），纵向居中，所有行左侧对齐 left=4。
- fill：`#26201E` flood-opacity 0.5（半透明灰，独立 alpha，不用元素级 opacity）。
- 内阴影：`feOffset dx=1 dy=1`（棱宽 1px，左/上棱 → 凹陷朝右下）→ 原字形减偏移字形 → `feGaussianBlur stdDeviation=0.2` → 与 SourceAlpha 相与 → `feFlood #000 flood-opacity=0.5`。
- stroke（最上层单独 `<text>`）：`fill:none; stroke:#b4887c; stroke-width:1px; paint-order:stroke`。
- 文案与第二三列一致：系统设定 / 游戏设定 / ADV设定 / 声音设定 / 角色设定 / 操作设定。
- 渲染预览页：`.tmp\so009b_col1_render.html`（4× 放大与原图同比例对照）。

### 8.2 待验证：ADV 拉丁字形宽度异常（怀疑与操作系统字体有关）

**现象**：28px（bold）下渲染「ADV设定」，ADV（3 个拉丁字符）实测宽度 **57.63px（bold）/ 56.06px（regular）**，而「设定」（2 汉字）56.00px——**ADV 与两汉字等宽甚至更宽**。与既有经验（20px 时 ADV=37px < 设定=40px，窄 3px，曾专门插入 3px 间隔补齐）**相反**。

**测量数据（macOS + headless Chrome）**：

| 项目 | 宽度 |
|---|---|
| PIL 读 WenQuanYi.ttf 度量（28px）「ADV」 | 52.00px |
| PIL 读 WenQuanYi.ttf 度量（28px）「设定」 | 56.00px |
| 浏览器渲染（28px, regular）「ADV」 | 56.06px |
| 浏览器渲染（28px, regular）「设定」 | 56.00px |
| 浏览器渲染（28px, bold）「ADV」 | 57.63px |
| 浏览器渲染（28px, bold）「设定」 | 56.00px |
| 浏览器渲染 SVG `<text>`「ADV设定」（28px bold） | 113.63px |

**分析**：PIL 字体度量 ADV 应窄 4px，但浏览器渲染中 ADV≈汉字宽；bold 仅撑宽拉丁字符（+1.57px）汉字不变；20px 与 28px 的 ADV/字符比例非线性（0.618em vs 0.667em）。**怀疑浏览器对 WenQuanYi 的拉丁字形渲染发生 fallback（回退到系统西文字体），与操作系统字体环境相关**。

**复现/构造方案**（自包含，待回 Windows 验证；`.tmp` 不进仓库，以下代码直接可用）：

1. 测量页（存为任意 `.html`，与 `res/fonts/WenQuanYi.ttf` 的相对路径按实际调整）：
   ```html

   <head>
   ```
