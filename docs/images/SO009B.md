## 6. 复现步骤

1. 清理原图第二、三列：

   输出 `.tmp\so009b_cleaned.png`。
2. 编辑渲染页 `.tmp\so009b_thirdcol_render.html`（CSS 与 left/top 参数）。
3. headless Chrome 截图（沙箱内会崩溃，需提权运行）：
   ```powershell
   & "C:\Program Files\Google\Chrome\Application\chrome.exe" --headless --disable-gpu `
     --no-first-run --user-data-dir="E:\Games\Eushully\天結\.tmp\chrome_tmp" `
     --screenshot="E:\Games\Eushully\天結\.tmp\so009b_thirdcol_cn.png" `
     --window-size=712,256 --force-device-scale-factor=1 `
     --default-background-color=00000000 `
     "file:///E:/Games/Eushully/天結/.tmp/so009b_thirdcol_render.html"
   ```
4. 有头注入 AGF（在 `scripts` 目录执行）：
   ```powershell
   node agf/cli.js inject "E:\Games\Eushully\天結\install\DATA1\SO009B.AGF" `
     "E:\Games\Eushully\天結\.tmp\so009b_thirdcol_cn.png" `
     -o "E:\Games\Eushully\天結\install\SO009B.AGF"
   ```
   输出：8bpp + ACIF，365,696 B。

## 7. 注意事项

- install 根目录 AGF 为 overlay，引擎读取优先于 ALF（已验证 SO005 生效机制）。
- `install\SO009B.AGF` 会改变 install-manifest 记录（`npm run check` 可见）；还原时从 `install\DATA1\SO009B.AGF` 复制覆盖即可。
- 有头注入为无压缩写入，产物体积明显大于原文件（84KB → 356KB），不影响本测试。
- 字体文件 WenQuanYi.ttf 已复制到 `.tmp\`（与渲染 HTML 同目录），页内 @font-face 加载。
