# AGF Toolkit Final

用于 Eushully / 部分使用 AGF 资源的游戏：**批量导出 AGF -> PNG**，以及 **PNG 导入回 AGF** 的图形化工具（GUI）。

> 本工具面向资源修改/汉化/美术替换用途。请务必先备份原文件，避免损坏游戏资源。

---

## 功能特性

- **导出 PNG（Extract）**
  - 支持：带 `ACGF` 文件头的 AGF
  - 支持：无头（`00 00 00 00` 开头）AGF
  - 支持模式：自动识别 / 强制有头 / 强制无头
  - 无头文件支持多结构探测（meta 偏移、body header 长度变种），尽量保证不花屏、不导错

- **导入 AGF（Import）**
  - **无头导入（PNG -> AGF）**
    - 直接将 PNG 打包成无头 AGF
    - 输出：**24bpp、无压缩**（兼容性高、速度快）
  - **有头注入（原AGF + PNG -> AGF）**
    - 需要提供：原始 AGF（作为骨架） + 同名 PNG
    - 会保留原文件结构（包括可能存在的 Alpha/ACIF 块）
    - 修复常见“注入后 GARbro 雪花/噪点”的问题（meta 压缩、stride/bpp 不一致、ACIF 位置/padding 等）

- **批量处理**
  - 导出：支持多选文件
  - 导入：支持文件夹批量（按同名匹配）

- **UI 体验**
  - 背景图随机切换（可自定义多张）
  - “玻璃面板”通透风格
  - 主题：System / Light / Dark（用户可切换，自动保存）

## 运行环境 / 依赖

如果你下载的是已打包好的 `AGF_Toolkit_Final.exe`：

- ✅ **不需要安装 Python**

## 使用说明

### 1) 导出 PNG（Extract）
1. 打开软件 → 进入 `导出PNG`
2. 选择识别模式：
   - **自动**：推荐
   - **强制有头**：仅用于确定是 ACGF 的文件
   - **强制无头**：仅用于确定是无头文件
3. （可选）选择导出文件夹  
   - 留空则默认导出到 AGF 同目录
4. 点击：`选择AGF文件并导出(可多选)`

输出：与原文件同名的 `.png`

---

### 2) 无头导入（PNG -> AGF）
适用于：你不需要保留“原始 ACGF 结构”，或者游戏使用无头 AGF 的资源。

1. 进入 `无头导入(PNG->AGF)`
2. 选择：
   - PNG 文件夹
   - 输出文件夹
3. 点击：`开始无头批量导入`

输出：生成同名 `.AGF`（24bpp、无压缩）

---

### 3) 有头注入（原AGF + PNG）
适用于：游戏资源是带 `ACGF` 头的文件，或者你需要保留原文件结构/透明通道等。

规则：按文件名匹配  
- `AAA.png` 会匹配 `原AGF文件夹/AAA.AGF`

步骤：
1. 进入 `有头注入(原AGF+PNG)`
2. 选择：
   - PNG 文件夹（放你改好的 png）
   - 原 AGF 文件夹（放游戏原始 agf）
   - 输出文件夹（放生成的新 agf）
3. 点击：`开始有头批量注入(同名匹配)`

输出：输出文件夹下生成同名 `.AGF`

建议：如果你改图后出现尺寸不一致，请先确认 PNG 尺寸是否与原始 AGF 对应图片一致。


## 注意事项（强烈建议阅读）

- **务必备份原始 AGF 文件**，建议复制一份到新目录再操作
- 有头注入模式：要求 PNG 与原 AGF 的目标图片 **尺寸一致**（否则会失败）
- 若你修改了 PNG 的透明度/Alpha：
  - 有头注入会尽量写回（若原文件存在 Alpha/ACIF 结构）
  - 无头导入会丢弃 Alpha（因为输出固定为 24bpp）

## 常见问题（FAQ）

### Q1：我电脑没有 Python 能用吗？
能用。exe 已包含 Python 运行时和依赖。

### Q2：exe 打不开/闪退？
- 尝试安装 **Microsoft Visual C++ 2015–2022 (x64)** 运行库  
- 检查杀毒软件是否拦截/隔离了文件

### Q3：杀毒误报怎么办？
PyInstaller onefile 常见误报：
- 将 exe 加入白名单
- 或放到信任目录

### Q4：导出 PNG 花屏/灰图？
通常是无头文件结构变种导致。建议：
- 尝试切换导出模式（强制无头/强制有头）
- 或把该文件样本发给作者进一步适配
